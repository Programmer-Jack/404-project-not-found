# 404: Project Not Found

Team Paid Programming's game for GAIM Game Jam 2026!
404: Project Not Found is a 3D side scroller runner game that requires the player to face obstacles and "glitches" while trying to beat the level. You race as Gaimie, the lovely mascot of the GaIM Live crew. Jump over obstacles, and click to close the popups when necessary. Will you be able to complete the level without a glitch?

Made with Unity in 11 hours for the GaIM Live Game Jam on 24 October 2026.
